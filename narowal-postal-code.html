Frequently Asked Questions

What is the postal code of Narowal?▼
The postal code of Narowal city is 51600. This covers Narowal city including DC Office, Main Bazaar, GT Road, College Road, Hospital Road and all main areas. For deliveries to Narowal city always use 51600.
What is the postal code of Shakargarh?▼
The postal code of Shakargarh is 51800. This covers Shakargarh city and surrounding areas in Shakargarh tehsil including Kartarpur area (51820) and rural sub-offices. For Shakargarh deliveries use 51800.
What is the postal code of Zafarwal?▼
The postal code of Zafarwal is 51700. This covers Zafarwal city and tehsil. For deliveries to Zafarwal use 51700 as the postal code.
What is Pakki Kotli Narowal postal code?▼
Pakki Kotli is an area within Narowal city. The postal code for Pakki Kotli Narowal is 51600 — the same as Narowal city main postal code.
How to find Pakistan Post tracking in Narowal?▼
Track your Pakistan Post parcel at pakpost.gov.pk using your tracking number. For queries contact GPO Narowal at 0542-412050 or Pakistan Post helpline 111-868-111.
